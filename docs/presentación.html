No es un 'port'. Es adaptación inteligente a los paradigmas nativos de cada plataforma.

Complejidad técnica: Bridges nativos (Swift/Kotlin ↔ JavaScript) · Testing en dispositivos reales · UX consistente con código divergente

iOS no permite overlays por seguridad → widgets interactivos. Android lo permite → aprovechamos floating overlay. Mismo objetivo, implementación específica óptima.

De concepto a usuarios reales en 12 semanas

  • Testing real campus
  • Feedback continuo
  • Iteración ágil
  • Quality assurance

Reto: Calidad production con timeline académico

Solución técnica destacada: Filtro de Kalman para fusionar múltiples fuentes → precisión submétrica

Técnico: Los sensores móviles no son perfectos. GPS error 5-10m. Implementé filtro Kalman para fusión. Plataforma: React Native da 80%. El 20% requiere código nativo. Bridges Swift/Kotlin manteniendo arquitectura compartida. Producto: Conseguir usuarios reales, feedback honesto, iterar rápido es tan difícil como el código.
